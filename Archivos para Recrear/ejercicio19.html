Protocolo Obligatorio de Cierre de Turno

Cada administrador debe validar la siguiente lista de acciones antes de cerrar sesión:

  1. Verificar que las tablas de stock no tengan valores negativos.
  2. Cotejar las cargas de archivos pesados.
    • Formatos aceptados: .pdf, .png, .jpg
    • Peso máximo por archivo: 10 Megabytes
  3. Asegurar que los tokens de seguridad coincidan con la base de datos cifrada.
